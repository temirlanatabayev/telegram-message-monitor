# Telegram Message Monitor

A Python-based Telegram monitoring tool that filters messages by specific keywords.

## Overview

This project monitors messages in a Telegram group and identifies messages that contain configured keywords. It was created to automate message monitoring and reduce the need for manual checking.

## Features

- Keyword-based message filtering
- Automated Telegram message monitoring
- Python implementation using Telethon
- Designed to run continuously on a Linux VPS

## Technologies

- Python
- Telethon
- Linux / Ubuntu VPS
- systemd

## Purpose

This project demonstrates practical experience with Python scripting, Telegram API integration, automation, and running a Python application on a Linux server.

## Security

Sensitive credentials, Telegram session files, tokens, and private information must not be included in this repository.
